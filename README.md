# 🩺 AI-Assisted Endoscopic Diagnostic Tool  

An AI-powered diagnostic system developed using **Vision Transformers (ViT)** for **endoscopic and gastroscopic image and video analysis**.  
Built in under 24 hours during **MOZOHACK 2025**, where it secured a **Top 10 position** among 200+ teams.  

---

## 🚀 Overview  
This project assists doctors in identifying gastrointestinal abnormalities using **deep learning and computer vision**.  
A custom **UI interface** was developed for students and clinicians to visualize predictions in real-time.  

---

## 🧠 Key Features  
- ⚡ **Vision Transformer (Hugging Face, PyTorch)** for image and video classification  
- 💻 **Interactive UI** for visualization and testing  
- 📈 **93% accuracy** achieved on multimodal datasets (images + videos)  
- 🧩 **Lightweight architecture** ready for integration with clinical systems  

---

## 🧩 Tech Stack  
- **Language:** Python  
- **Frameworks & Libraries:** PyTorch, Hugging Face Transformers, OpenCV, NumPy, Streamlit  
- **Tools:** Jupyter Notebook, Git, VS Code  

---

## ⚙️ Model Workflow  
1. Extract frames from endoscopic videos using OpenCV  
2. Preprocess and normalize images for ViT model input  
3. Classify abnormalities via a fine-tuned Vision Transformer  
4. Display live predictions and confidence scores through Streamlit UI  

---

## 📊 Results  
- **Accuracy:** 93% (validated on >5,000 samples)  
- **Inference Speed:** ~12 FPS on RTX 3060  
- **Achievement:** Ranked *Top 10* at **MOZOHACK 2025 (24-hour hackathon)**
